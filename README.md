🍕 Pizza Sales Analysis – MySQL Project
📌 Project Overview

This project focuses on analyzing pizza sales data using MySQL.
The goal is to derive insights such as:

Total revenue 💰

Best & worst-selling pizzas 🍕

Sales by category & size 📊

Peak order times ⏰

Customer buying trends 👥

🛠️ Tools & Technologies

MySQL – Data extraction & queries

SQL Joins, CTEs, Aggregations, Window Functions

Excel / CSV – Data source

📊 Key Insights

Top 5 best-selling pizzas 🍕

Revenue contribution by pizza size & category

Daily & monthly sales trends

Peak order hours

Most profitable products   


📌 Future Scope

Connect SQL data with Power BI / Tableau for visualization

Add automated reporting scripts in Python

Expand analysis with customer segmentation
